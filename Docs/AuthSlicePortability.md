## SDK and tool inputs

- The arm64 Swift 6.3.3 FoundationNetworking overlay is generated by
  `Scripts/android-networking-overlay.py` from checksum-verified upstream
  source. It does not modify the installed SDK. Keep it explicit until an SDK
  includes both cancellation fixes.
- The first cancellation fix is upstream PR 5417. The second completion guard
  still needs upstream review; the local stress reproducer is
  `Scripts/diagnostics/FoundationNetworkingCancellation.swift`.
- Select the overlay with `SWIFT_ANDROID_SDK_BUNDLE`; the Android build derives
  the matching runtime location and checks the packaged library's hash.
- Set `SKIPLOCAL` to the intended Skipstone checkout. Its sibling Skip package
  routes must include the reviewed changes above. The Android harness can build
  its own managed SkipRunner; a temporary executable supplied through
  `SKIP_COMMAND_OVERRIDE` is not a portable artifact.
- Supply `GRADLE_BIN` explicitly. Device IDs and installed toolchains are
  machine-specific inputs, not checked-in constants.
- Local package overrides remain development inputs until publication:
  `OME_COMPOSABLE_ATMOSPHERE_PATH`, `OME_FILE_TREE_PATH`,
  `OME_CLOCKS_PATH`, `OME_CUSTOM_DUMP_PATH`, `OME_DEBUG_SNAPSHOTS_PATH`,
  and `OME_SKIP_AUTHENTICATION_SERVICES_PATH`.
  Each path's final component must be the canonical package identity.

## Completion criteria for a clean-machine build

1. Reconcile and land shared auth while preserving canonical checkout work.
2. Publish owned package changes and obtain reviewed third-party fixes.
3. Replace temporary overrides with available package versions or main-reachable
   revisions; record the selected toolchain, Skip, Gradle, and runtime inputs.
4. Bootstrap in a fresh directory without developer-workspace symlinks, a
   prebuilt temporary SkipRunner, or a Codex installation.
5. Run host/platform/Compose tests, deterministic UI/image tests, and both private
   auth/recovery suites there.

The new Lexicon integration is a subsequent slice. Keep its changes separate
from this auth/dependency reconciliation.
