# High-Level Roadmap

This page is the index for the ATProtoOME roadmap. Each roadmap item has its
own card under `roadmap/` so it can be linked, expanded, and moved independently.

The first frame is the native app. ATProto, Tangled, source repositories, and
Skip are supporting infrastructure for identity, distribution, editing,
publishing, and cross-platform delivery.

Code pointers are relative to this repository unless a card says otherwise.

## Board

[[Roadmap-Kanban|Roadmap Jira Board]] is the canonical status board. Move
cards between its headings to update status.

Board headings are the canonical status. Card frontmatter is metadata for Base
filtering and sorting only. `Blocked` means meaningful progress is waiting on a
dependency, not merely that the card is incomplete.
