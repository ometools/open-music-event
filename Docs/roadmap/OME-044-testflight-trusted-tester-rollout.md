# TestFlight / Trusted Tester Rollout

## Summary

Plan the first trusted tester rollout for iOS and the matching Android path when ready.

## Why

The app needs feedback from real event organizers and attendees before a broad release, especially around source content, schedule browsing, and event polish.

## Rough Shape

- Collect tester emails and invite users through TestFlight for the first iOS round.
- Track Android tester readiness separately until Android parity is reliable.
- Use tester feedback to prioritize attendee-facing polish and organizer editing work.
- Code pointers: `Darwin/fastlane`, `Android/fastlane`.

- Which workflows must be stable before inviting testers?
