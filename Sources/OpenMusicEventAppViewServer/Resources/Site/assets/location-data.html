Location data credits

Coordinate-derived countries and time zones use SwiftTimeZoneLookup 1.0.8 and ZoneDetect.

The bundled boundary dataset is version 2024a. Contains public-domain data from Natural Earth and data from timezone-boundary-builder under the Open Database License. Inferences can be imperfect near borders; explicit event information takes precedence.
